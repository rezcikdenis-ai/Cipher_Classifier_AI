# 🔐 Cipher Classifier

ML-классификатор криптографических шифров на основе Random Forest.

## Описание

Программа определяет тип шифра по зашифрованному тексту, загружаемому в виде `.txt` файла. Используется анализ статистических характеристик текста: частоты букв, индекс совпадений, энтропия Шеннона, биграммы и другие признаки.

**Поддерживаемые шифры:**
- Открытый текст (plaintext)
- Шифр Цезаря
- Шифр Виженера
- Шифр Rail Fence
- Шифр Атбаш
- Шифр Плейфера
- Шифр Бэкона

**Точность модели:** 91.7% на тестовой выборке (7 классов, 2100 примеров)

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/<your-username>/cipher-classifier.git
cd cipher-classifier
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Запустить модули по порядку

Открыть Jupyter:

```bash
jupyter notebook
```

Затем запускать ноутбуки в порядке:

1. `module1_dataset.ipynb` — генерирует `cipher_dataset.csv`
2. `module2_classifier.ipynb` — обучает модель, сохраняет `cipher_model.pkl`
3. `module3_interface.ipynb` — запускает веб-интерфейс на `http://127.0.0.1:7860`

## Требования

- Python 3.9+
- См. `requirements.txt`

## Как пользоваться интерфейсом

1. Запустить `module3_interface.ipynb` до конца
2. Открыть `http://127.0.0.1:7860` в браузере
3. Загрузить `.txt` файл с зашифрованным текстом (только латинские буквы, минимум 20 символов)
4. Нажать «Определить шифр»

## Математическая основа

Для каждого текста извлекается вектор из **40 признаков**:

| Признак | Формула | Количество |
|---|---|---|
| Частоты букв | $f_i = \frac{n_i}{N}$ | 26 |
| Индекс совпадений | $IC = \frac{\sum n_i(n_i-1)}{N(N-1)}$ | 1 |
| Энтропия Шеннона | $H = -\sum p_i \log_2 p_i$ | 1 |
| Уникальных букв | — | 1 |
| Частоты биграмм | TH, HE, IN, ... | 10 |
| Удвоенные пары | — | 1 |

Классификатор — **Random Forest** (200 деревьев).
